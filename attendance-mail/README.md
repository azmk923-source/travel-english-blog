# 勤務時間13時間超過防止 メール自動送信

打刻時刻を入力する **Excel ファイル** と、メールを送る **実行ファイル** を分けています。

| ファイル | 役割 |
|---|---|
| `勤務時間管理.xlsx` | 従業員名・メールアドレス・出勤打刻時刻を入力するだけのファイル |
| `メール送信.vbs` | ダブルクリックで全員に一斉送信する実行ファイル（Excel + Outlook を裏で操作） |

必ず **同じフォルダ** に置いてください。

## 1. Excel（勤務時間管理.xlsx）

「勤怠」シート

| 列 | 内容 |
|---|---|
| A 氏名 | 従業員名 |
| B メールアドレス | 送信先 |
| C 出勤打刻時刻 | **`8:05` のように時刻だけ入力（日付は不要）** |
| D 13時間経過時刻 | 自動計算（C+13時間） |
| E 送信済み日付 | 実行ファイルが自動で書き込む（触らない） |
| F 備考 | 任意 |

- 日付欄はありません。時刻だけを入力する運用です（`{date}` を使えば本文に本日の日付を自動で入れられます）。
- C 列は時刻以外を弾く入力規則付きです。

「設定」シート（変更可）

- 上限時間 … 既定 13
- 送信可能開始時刻 … 既定 `9:00`（これより前に実行しても送信されません）
- 午前打刻とみなす上限 … 既定 `12:00`（これ以降の打刻＝午後出勤者は送信対象外）
- 件名 … `{name} {in} {limit} {remain} {hours} {date}` が使えます
- CC … 全員共通の CC（任意）
- 送信後に打刻をクリア … 既定 `ON`（送信できた行の C 列を自動で消す。`OFF` で残す）

「本文」シート … 3行目以降がメール本文。同じ差し込みタグが使えます。

## 2. 送信（メール送信.vbs）

夕方にダブルクリックするだけ。処理内容:

1. 現在時刻が 9:00 前なら中止（メッセージを出して終了）
2. 打刻が 12:00 以降の行（午後出勤者）はスキップ
3. E 列の送信済み日付が本日の行はスキップ → **2回以上開いてもメールは重複しません**
4. 13時間到達時刻までの残りを **「○時間○分」** で本文に差し込み、Outlook で送信
5. 送信できた行だけ E 列に本日の日付を記録し、設定が `ON` なら C 列の打刻を消してから保存
6. 最後に「送信◯件 / スキップ◯件 / 失敗◯件」の結果を表示

すでに13時間を超えている人には「0時間0分（○時間○分超過）」と表示されます。

### 休みの人（打刻を入力しない人）

C 列が空の行は対象外です。メールは送られず、E 列も更新されず、件数にも入りません。
入力するのは出勤した人だけで構いません。

前日の打刻が残っていると翌日も出勤扱いになってしまうため、既定では
**送信できた行の C 列を送信後に自動でクリア**します（設定シートの「送信後に打刻をクリア」）。
打刻を記録として残したい場合は `OFF` にし、翌朝の入力前に C 列を消す運用にしてください。

### 毎日自動で実行したい場合

Windows の「タスク スケジューラ」で
`wscript.exe "C:\...\attendance-mail\メール送信.vbs"` を平日 17:00 などに登録してください。
（結果ダイアログを出したくない場合は最後の `MsgBox` 行を削除）

### 必要環境

Windows / Microsoft Excel / Outlook（デスクトップ版、プロファイル設定済み）。
Outlook 以外（Gmail SMTP など）で送りたい場合は言ってください。CDO 版に差し替えます。
