======================================================================
 勤務時間13時間超過防止 メール自動送信  使い方
======================================================================

■ ファイル構成（必ず同じフォルダに置いてください）

  勤務時間管理.xlsx … 打刻時刻を入力するファイル
  メール送信.vbs    … ダブルクリックで一斉送信する実行ファイル
  使い方.txt        … このファイル

----------------------------------------------------------------------
■ 1. 入力（勤務時間管理.xlsx）
----------------------------------------------------------------------

「勤怠」シート

  A列 氏名           … 従業員名
  B列 メールアドレス … 送信先
  C列 出勤打刻時刻   … 8:05 のように時刻だけ入力（日付は不要）
  D列 13時間経過時刻 … 自動計算（C列＋13時間）
  E列 送信済み日付   … 実行ファイルが自動で書き込む（触らない）
  F列 備考           … 任意

  ・日付欄はありません。時刻だけを入力する運用です。
    本文に日付を入れたい場合は {date} を使ってください。
  ・C列は時刻以外を入力するとエラーになります。
  ・休みの人は空欄のままでOK。メールは送られません。

「設定」シート（必要に応じて変更）

  上限時間               … 13
  送信可能開始時刻       … 9:00（これより前は送信しません）
  午前打刻とみなす上限   … 12:00（これ以降の打刻＝午後出勤者は対象外）
  件名                   … 差し込みタグが使えます
  CC                     … 全員共通のCC（任意）
  送信後に打刻をクリア   … ON（送信できた行のC列を自動で消す）／OFFで残す

「本文」シート

  3行目以降がメール本文です。次のタグが差し込まれます。

    {name}   氏名
    {in}     出勤打刻時刻
    {limit}  13時間に到達する時刻
    {remain} 残り時間（○時間○分）
    {hours}  上限時間（13）
    {date}   本日の日付

----------------------------------------------------------------------
■ 2. 送信（メール送信.vbs をダブルクリック）
----------------------------------------------------------------------

  1. 現在時刻が 9:00 前なら中止（メッセージを出して終了）
  2. 打刻が 12:00 以降の行（午後出勤者）はスキップ
  3. E列の送信済み日付が本日の行はスキップ
     → 2回以上実行してもメールは重複しません
  4. 13時間到達までの残り時間を「○時間○分」で本文に差し込み、
     Outlook で送信
  5. 送信できた行だけ E列に本日の日付を記録し、
     設定が ON なら C列の打刻を消してから保存
  6. 最後に 送信◯件 ／ スキップ◯件 ／ 失敗◯件 を表示

  ※すでに13時間を超えている人には
    「0時間0分（○時間○分超過）」と表示されます。

----------------------------------------------------------------------
■ 3. 毎日自動で実行したい場合
----------------------------------------------------------------------

  Windows の「タスク スケジューラ」で、平日17:00 などに次を登録します。

    プログラム : wscript.exe
    引数       : "C:\Users\azuma\Desktop\13時間メール送信\メール送信.vbs"

  ※パスはご自分のフォルダに合わせてください。
  ※結果ダイアログを出したくない場合は、vbs 内の最後の MsgBox の行を
    削除してください。

----------------------------------------------------------------------
■ 4. 必要な環境
----------------------------------------------------------------------

  Windows ／ Microsoft Excel ／ Outlook（デスクトップ版・設定済み）

  Outlook 以外（Gmail の SMTP など）で送りたい場合は、
  その方式に差し替えられます。

----------------------------------------------------------------------
■ 5. よくあるトラブル
----------------------------------------------------------------------

  ・「文字が正しくありません 800A0408」と出る
      → vbs の文字コードの問題です。メモ帳で開き、
        「名前を付けて保存」→ 文字コードを ANSI にして保存し直す。

  ・9時前に実行して何も送られない
      → 仕様です。9:00 以降に実行してください。

  ・休みの人にメールが届いた
      → 前日の打刻が C列に残っています。
        設定シートの「送信後に打刻をクリア」を ON にしてください。
