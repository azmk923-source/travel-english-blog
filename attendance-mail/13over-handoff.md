# 13時間超過防止メール システム 引き継ぎ資料

最終更新: 2026-08-30
ブランチ: `claude/excel-auto-email-system-k86ome`

## 1. 目的

ドライバーの労働時間が13時間を超えないよう、各自の出勤打刻時刻から13時間後の
到達時刻を、午前中に本人へ一斉メール送信する。

## 2. ファイル構成

`attendance-mail/` フォルダに以下3ファイル。実運用では同じフォルダに置くこと。

| ファイル | 役割 |
|---|---|
| `勤務時間管理.xlsx` | 入力用。氏名・メールアドレス・出勤打刻時刻を入れる |
| `メール送信.vbs` | 実行用。ダブルクリックで送信 |
| `使い方.txt` | 現場向けの操作手順（メモ帳で開ける） |

入力ファイルと実行ファイルは分離してある（要件）。

## 3. Excelのシート構成

### 勤怠シート

| 列 | 内容 |
|---|---|
| A | 氏名 |
| B | メールアドレス |
| C | 出勤打刻時刻（`7:45` のように半角で時刻入力。日付は入れない） |
| D | 13時間経過時刻（数式 `=IF(N(C2)=0,"",C2+TIME(13,0,0))`） |
| E | 送信済み日付（スクリプトが自動で書き込む。重複送信防止用） |
| F | 備考 |

2行目から201行目まで使用可能。C列には時刻の入力規則を設定済み。

### 設定シート

| 項目 | 値 | 説明 |
|---|---|---|
| 上限時間 | 13 | 何時間を上限とするか |
| 送信可能開始時刻 | 9:00 | この時刻より前は実行しても送信しない |
| 午前打刻とみなす上限 | 12:00 | これ以降の打刻は午後出勤としてスキップ |
| 件名 | 【安全のお知らせ】本日の13時間到達時刻は {limit} です | |
| 差出人表示名 | 勤怠管理 | |
| CC | （空欄） | 全員のメールにCCを入れたい場合のみ記入 |
| 送信後に打刻をクリア | ON | 送信成功後にC列を消す。翌日の誤送信防止 |

### 本文シート

A3セル以降に本文を1行ずつ入力。空行はセルを空のままにする。
差し込み記号: `{name}` 氏名 / `{in}` 出勤打刻 / `{limit}` 13時間到達時刻 /
`{remain}` 残り時間（○時間○分） / `{hours}` 上限時間 / `{date}` 日付

現在の本文:

```
{name} さん　お疲れさまです。

　出勤打刻　　{in}
　13時間到達　{limit}（残り {remain}）

{limit} を目安に、無理のない範囲でご調整ください。
超えそうなときは早めに配車担当へご連絡ください。会社側で調整します。

※運転中は見ないでください。急ぐ必要はありません。安全が最優先です。
※自動送信のため返信は不要です。
```

文面の方針: ドライバーを焦らせると事故につながるため、命令形を避け、
超過を個人の責任にせず、連絡すれば会社が調整するという出口を明示している。
「配車担当」は各社の実際の呼称に合わせて変更すること。

## 4. スクリプトの動作

1. 同フォルダの `勤務時間管理.xlsx` を開く
2. 読み取り専用で開かれた場合は中止（後述の注意点を参照）
3. 現在時刻が「送信可能開始時刻」より前なら何もせず終了
4. 勤怠シートを2行目から順に処理
   - 氏名・メールアドレス・C列のいずれかが空の行はスキップ（＝休みの人は安全にスキップ）
   - E列に今日の日付が入っていればスキップ（＝2回実行してもメールは重複しない）
   - 打刻が12:00以降なら午後出勤としてスキップ
   - Outlookでメール送信
   - 成功したらE列に今日の日付を書き込み、C列をクリア
5. 保存して閉じ、結果を集計してダイアログ表示

メール送信にはOutlookを使用（`Outlook.Application`）。Outlookが起動している必要がある。

## 5. 運用上の注意点（重要）

**実行時は `勤務時間管理.xlsx` を必ず閉じておくこと。**

Excelで開いたまま実行すると読み取り専用で開かれ、メールは送られるのに
E列の日付とC列のクリアが保存されない。翌日に同じ打刻が残ったまま
再送される可能性がある。

リポジトリの `メール送信.vbs` には、この状態を検知して1通も送らずに
警告して中止する安全装置が入っている。現場で使用中のファイルが
この版かどうかは、ファイルサイズで確認できる（安全装置あり = 約8.26 KB）。

## 6. タスクスケジューラでの自動実行

1. タスクスケジューラを開く →「基本タスクの作成」
2. 名前を入力（例: 勤怠13時間メール）
3. トリガー: 毎日、開始時刻を9:00以降に設定
4. 操作:「プログラムの開始」
   - プログラム: `wscript.exe`
   - 引数: `"C:\...\メール送信.vbs"`（フルパスをダブルクォートで囲む）
5. 完了後、タスクを右クリック→実行でテスト。結果が `0x0` なら成功

無人実行する場合は、`メール送信.vbs` の末尾にある `MsgBox "送信完了"` の
ブロックを削除するとダイアログが出なくなる。

前提: PCが起動しログイン済みであること、Outlookが起動していること、
その時間帯にExcelファイルが開かれていないこと。

## 7. .vbs を編集するときの注意

- **文字コードは Shift_JIS（CP932）、BOMなし**。UTF-8で保存すると
  `800A0408 文字が正しくありません` エラーになる
- メモ帳で編集する場合は **Ctrl+S で上書き保存**。「名前を付けて保存」を
  使うと文字コードが変わって動かなくなる
- VBScriptはVBAではない。`24#` のような型サフィックスは使えない
- `Int()` はこの環境で型不一致を起こしたため全て除去済み。使わないこと

### よくあるエラー

| エラー番号 | 原因 |
|---|---|
| 800A0408 | ファイル先頭にBOMがある |
| 800A0401 | 構文エラー（VBA固有の記法を使っている等） |
| 800A01F4 | 変数の宣言漏れ（`Dim i, v` を `Dim i : v` と書いた等） |
| 800A03EE | 括弧の対応が取れていない |
| 800A000D | 型が一致しない（時刻の扱い） |

## 8. 経緯メモ

- 打刻値をExcelに文字列で入れると型不一致になるため、時刻値として入力すること
- README.md は現場でメモ帳から読めるよう `使い方.txt`（UTF-8 BOM付き・CRLF）に変更
- ファイル転送は zip にまとめると文字化けせず届く
